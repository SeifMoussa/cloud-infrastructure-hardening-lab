# Contributing

Thank you for considering a contribution to Cloud Infrastructure Hardening Lab.

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies:

```bash
pip install -e .
```

4. Run tests:

```bash
python -m pytest
```

5. Run the linter:

```bash
python -m ruff check .
```

6. Submit a pull request with a clear description.

Do not add real credentials, live cloud identifiers, real customer data, public infrastructure targets, or offensive security content.
